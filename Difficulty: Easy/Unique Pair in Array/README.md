<h2><a href="https://www.geeksforgeeks.org/problems/find-unique-pair-in-an-array-with-pairs-of-numbers2425/1">Unique Pair in Array</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color); --darkreader-text--text-color: var(--darkreader-text--problem-text-color); --darkreader-border--text-color: var(--darkreader-border--problem-text-color);"><p><span style="font-size: 18px;"><span style="font-size: 18px;">Given an array <strong>arr[]</strong> in which every element appears exactly twice except for two elements that appear only once, find those two unique elements and return them in sorted order.</span></span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> arr[] = [2, 2, 5, 5, 6, 7]
<strong>Output:</strong> [6, 7]
<strong>Explanation: </strong>2 and 5 appear twice, while 6 and 7 appear only once.
</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> arr[] = [1, 3, 4, 1]
<strong>Output:</strong> [3, 4]<br><strong>Explanation: </strong>1 appears twice, while 3 and 4 appear only once.</span></pre>
